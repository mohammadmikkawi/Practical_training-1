# مشروع موقع مؤسسة بن مكاوي

## وصف المشروع
موقع إلكتروني لمؤسسة بن مكاوي الموجودة في نابلس، متخصصة في تحميص القهوة الإثيوبية وبيع الشاي المعبأ والبهارات.  
الموقع تم تصميمه باستخدام HTML5 و Bootstrap 5 ليتناسب مع جميع أحجام الشاشات ويقدم تجربة مستخدم سهلة وجذابة.

## المميزات
- تصميم متجاوب باستخدام نظام الشبكة في Bootstrap 5.  
- شريط تنقل ثابت مع قوائم منسدلة.  
- معرض صور متحرك (Carousel) لعرض المنتجات.  
- بطاقات (Cards) لعرض تفاصيل المنتجات.  
- نموذج اتصال مصمم بـ Bootstrap مع تحقق بسيط.  
- صفحات متعددة تشمل: الرئيسية، عن المؤسسة، القهوة المحمصة، الشاي والبهارات، معرض الصور، اتصل بنا، سياسة الخصوصية، سياسة الإرجاع، الشروط والأحكام، الأسئلة الشائعة.

## الهيكلية
- `index.html` - الصفحة الرئيسية  
- `about.html` - صفحة عن المؤسسة  
- `services.html` - القهوة المحمصة  
- `album.html` - الشاي والبهارات  
- `portfolio.html` - معرض الصور  
- `contact.html` - صفحة الاتصال  
- `privacy.html` - سياسة الخصوصية  
- `return.html` - سياسة الإرجاع  
- `terms.html` - الشروط والأحكام  
- `faq.html` - الأسئلة الشائعة  
- `css/styles.css` - ملف CSS مخصص (اختياري)

## كيفية التشغيل
1. فك ضغط مجلد المشروع.  
2. افتح أي ملف `.html` في المتصفح (مثل Chrome أو Firefox).  
3. تأكد أن جهازك متصل بالإنترنت لتحميل مكتبات Bootstrap من CDN.  
4. يمكنك التنقل بين الصفحات عبر شريط التنقل.

## المتطلبات
- متصفح حديث يدعم HTML5 و CSS3 و JavaScript.  
- اتصال إنترنت لتحميل مكتبات Bootstrap من CDN.

## ملاحظات
- تم استخدام Bootstrap 5 CDN لسهولة الاستخدام وسرعة التحميل.  
- يمكنك تعديل ملف `css/styles.css` لإضافة تخصيصات تصميمية حسب الحاجة.
